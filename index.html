UX Strategy

My goal: Build a fast, mobile-first website focused on storytelling.

I wanted to create a portfolio that demonstrates my skills through the experience itself, not just by talking about them.

Navigation is kept minimal to reduce cognitive load.

Only essential sections are included to guide visitors without overwhelming them with choices.

I structured content in scroll-based narrative flow to guide visitors.

The linear scroll journey takes you through my thought process from strategy to execution.

      // JavaScript for scroll animations
      const sections = document.querySelectorAll('.section');
      
      function checkScroll() {
          sections.forEach(section => {
              const sectionTop = section.getBoundingClientRect().top;
              if (sectionTop < window.innerHeight - 100) {
                  section.classList.add('visible');
              }
          });
      }
      
      // Initialize scroll event
      window.addEventListener('scroll', checkScroll);
      window.addEventListener('load', checkScroll);

SEO Strategy & Implementation

On-Page Optimization

  • Keyword Research: Tools like SEMrush and Google Keyword Planner to identify target terms
  • Content Optimization: Strategic placement of keywords in headings, alt text, and meta descriptions
  • Semantic Markup: Schema.org structured data for rich snippets
  • Internal Linking: Strategic anchor text and content siloing

Technical SEO

  • Performance: 95+ Lighthouse scores through code splitting and asset optimization
  • Mobile-First: Responsive design with Google's Mobile-Friendly Test validation
  • Security: HTTPS implementation with HSTS and secure headers
  • Crawling: Optimized robots.txt and XML sitemap with priority indexing
